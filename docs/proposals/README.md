# 需求与设计提案

新提案使用 `YYYYMMDD-topic.md` 命名。正文按以下顺序组织：

1. 使用场景、反馈来源和日期。
2. 当前行为、问题及期望结果。
3. 涉及模块、技术方案和取舍。
4. 验收条件、优先级和工作量。
5. 与 SPEC、ROADMAP 的关系。
6. 负责人决定及日期。

提案通过文档 PR 讨论。负责人批准后更新 SPEC 和 ROADMAP，再拆分实现任务。
