# P6/P7 模型访问管理后端交付

日期：2026-11-20。状态：本机实现与验证完成后提交 PR，由负责人审核合并。

本增量提供可信应用身份、模型许可、RPM、停用、治理审计和独立管理 API。复用原锁 LiteLLM 1.106.5 OSS 认证扩展与 PyJWT；私钥和 token 只由自动演示在内存生成。4000 允许表、8788 只读控制台和旧 8787 保持边界。启动及接口说明见 [SETUP §5](SETUP.md#5-模型访问管理后端演示)。

## 复核与限制

独立只读复核指出：请求级 fallback 可绕过仅检查主模型的授权；演示和复制主密钥参数的互斥检查晚于复制操作。两项均已修复并增加回归测试。另将保留端口冲突按已有端口隔离约束处理；演示结果把审计字段改为实际验证的记录条目，事务原子性由独立失败回滚测试证明。

应用策略变更与审计同事务；存储失败返回失败。RPM 为 UTC 自然分钟窗口，边界可短时突发；已准入请求在上游失败后仍计入，应用停用不取消在途请求。治理库无凭据，事件库仍尽力投递。完整演示只证明合成应用/模型别名组合及元数据归属，不证明两家真实供应商、生产性能或企业身份系统集成。

本轮接口没有登录页面，信任公钥和管理员名单重启生效；正式凭据发放、轮换、企业 IdP 与管理界面进入下一增量。旧 P4.2 未收尾项、P4.3 对账、P4.4 本地模型继续延期。完整第一产品版本和第二产品版本均由负责人逐项验收；项目许可证在正式试用发布前决定。

## 不做的事

不改 legacy、AstrBot、前端、锁文件和历史证据；不安装 prisma/enterprise、不自研虚拟 Key、不做真实调用、工具广场、Token/费用预算、正文采集、可靠调用投递；不自动合并，不进入下一增量。
